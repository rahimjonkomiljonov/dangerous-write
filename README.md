Dangerous Write

Welcome to Dangerous Write—an intense writing challenge app! This Python program tests your typing stamina. You have 5 minutes to write as much as you can, but if you stop typing for 5 seconds, all your progress vanishes! It’s perfect for a quick writing sprint or to beat writer’s block.

How to Use

Install Python: Make sure you have Python 3.x installed on your computer. You can download it from python.org.
Install Tkinter: Tkinter usually comes with Python, but if it’s missing, install it with your package manager (e.g., pip install tk on some systems).
Run the App: Save the code in a file named dangerous_write.py. Open a terminal, navigate to the folder, and run python dangerous_write.py.
Start Writing: Click the green "Start" button. Type in the text box—keep going to avoid losing your work!
End Session: After 5 minutes, the session ends. Use the "Copy to Clipboard" button to save your text or "Restart" to try again.

Features

Word Counter: Tracks how many words you’ve written.
Inactivity Timer: Deletes your text if you pause for 5 seconds.
Time Limit: Ends after 5 minutes with a congratulatory message.
Copy Option: Lets you save your work to the clipboard.

Customization Ideas

Change the 5-second inactivity timer to 10 seconds by editing the 5000 value in the reset_inactivity_timer function.
Make the window bigger by updating the geometry("600x400") to something like 800x600.
Add colors or sound effects (using a library like pygame) for extra fun!
